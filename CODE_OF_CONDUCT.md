# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work, and do not harass anyone.
Everyone participating in issues, pull requests and discussions is expected to follow it.

## Reporting

Report unacceptable behaviour privately to the maintainer through the contact options on the
[maintainer's GitHub profile](https://github.com/yodem), or, for anything that also has a security
angle, through the repository's private vulnerability reporting (see [SECURITY.md](SECURITY.md)).
Reports are handled confidentially. Enforcement follows the Covenant's community impact guidelines.
